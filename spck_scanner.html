It won't connect
  1. Same Wi-Fi. The phone and the laptop must be on one network. Phone data will not reach it.
  2. Current IP. On the laptop run ipconfig and use the IPv4 address. It changes whenever the laptop rejoins Wi-Fi.
  3. Include the folder. If the site is not at the server root, add it: 192.168.1.5/SAD.
  4. Apache running. Start Apache in the XAMPP control panel.
  5. Windows Firewall. Allow Apache on private networks, or the phone's request is dropped with no error.
